### Телеграм-бот для сбора информации о студентах
* Задача: собрать данные студентов для старост групп
* Хранение контекста в БД
* Интерфейс ввода фиксированных значений из списка и свободный ввод
* Выгрузка собранных данных в Excel

``` bash

python3 -m venv .venv
source /projects/guga_bot/.venv/bin/activate
```

Формы
Типы
1. Меню с кнопками
2. Ожидание ввода параметра (кнопкой, через callback, например пол)
3. Ожидание ввода параметра строкой(числом), контроль по регулярке

У класса формы 2 метода:
1. Отобразить (отправить сообщение) меню с кнопками или фразу типа: "Введите Ваш возраст:"
   Установить поля контекста, сохранить(обновить) контекст в БД
   В качестве параметра принимает user_id и предыдущий контекст (имя формы, из которой он был вызван)
   Возвращает контекст
   Главный класс сохраняет поля контекста в БД (на случай перезапуска бота)
   Если в контексте есть поля "user_data_name" и "user_data_value" - то 

2. Принять update (текстовое сообщение. в том числе forwarded, или callback)
   Если пользователь ввёл корректные данные: 
   а) вносит данные в БД
   б) очищает диалог
   в) устанавливает в контекст имя родительской формы
   возвращает контекст
   
   Если пользователь ввёл НЕкорректные данные:
   а) очищает сообщение пользователя
   б) возвращает текущий контекст
3. Callback-и всегда поступают вида
   form_step1|choice2
   где: 
     form_step1 - форма, в которой пользователь нажал на кнопку
     choice2 - payload этой кнопки

4. Пример контекста:
{
    "current_form": "gender",
    "prev_form": "profile",
    "action": "form_2",
    "last_bot_message_id": 12345,
    "last_user_message_id": 9785,
    "params": {
        "gender": "22"
    }
}
